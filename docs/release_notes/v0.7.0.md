# docstub 0.7.0

We're happy to announce the feature release of docstub 0.7.0 on 2026-11-08.
This release supports Python 3.12 to 3.15.

## Enhancement

- **Include shape information when translating doctypes** to annotations with `numpy.typing.NDArray`. This includes support for shapes with optional dimensions which use expansion like in the plugin example to create a union of arrays – one for each supported rank. Shapes with "..." are treated as an unspecified number of dimensions and are transformed to `tuple[Any, ...]`. Empty shapes are supported too ([#132](https://github.com/scientific-python/docstub/pull/132)).
- **Add a new plugin system** to Docstub with 2 hooks. These hooks allow overriding/extending the default grammar and  transformer that are used to transform doctypes into annotations. Add a minimal guide and documentation too ([#130](https://github.com/scientific-python/docstub/pull/130)).
- Support for callable expressions like `Callable[[int, str], int]` in doctypes ([#123](https://github.com/scientific-python/docstub/pull/123)).
- Ensure that sources (file paths and line numbers) in command line output are sorted "naturally". For example `foo.py:9` should go before `foo.py:24` ([#119](https://github.com/scientific-python/docstub/pull/119)).
- Log warnings emitted while parsing docstrings with NumPyDoc and link to the file and line number of the docstring ([#55](https://github.com/scientific-python/docstub/pull/55)).
- Color debug information with "green" which might be more visible with different color schemes than the previous "bright_black" ([#124](https://github.com/scientific-python/docstub/pull/124)).
- When printing debugging information (`-vv`), include command line arguments and the fully merged configuration in the output ([#124](https://github.com/scientific-python/docstub/pull/124)).
- Declare (official) support for Python 3.15 ([#128](https://github.com/scientific-python/docstub/pull/128)).

## Performance

- Avoid overusing libcst's "slower" `findall` ([#121](https://github.com/scientific-python/docstub/pull/121)).
- Cache transformed doctypes in each worker. Aggregated cache statistics are printed when showing debug information (`-vv` option) ([#130](https://github.com/scientific-python/docstub/pull/130)).

## Bug Fixes

- Add support for expressions like `Literal[1, "some string"]` in doctypes. The grammar previously only allowed names inside this form ([#55](https://github.com/scientific-python/docstub/pull/55)).
- Expand arrays whose dtype is a union of dtypes into a union of arrays, one for each given dtype. This might be necessary if `numpy.typing.dtype` does not support unions as arguments ([#132](https://github.com/scientific-python/docstub/pull/132)).
- Strip shape and dtype from *ArrayLikes* when converting them to an annotation since `numpy.typing.ArrayLike` doesn't support adding that information ([#132](https://github.com/scientific-python/docstub/pull/132)).
